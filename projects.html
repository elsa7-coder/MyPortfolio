Simple Calculator

A calculator that adds, subtracts, multiplies and divides.

How I built it

  1. Designed the command-line interface to prompt the user for numbers and operations.
  2. Implemented separate arithmetic functions for addition, subtraction, multiplication, and division.
  3. Added a divide-by-zero check to prevent runtime errors and provide clear error messages.
  4. Wrapped operations in a loop with a switch statement allowing continuous calculations until exit.

Technologies Used

  • C++
  • Standard I/O Streams (iostream)
  • I/O Manipulators (iomanip)
  • GCC / g++ Compiler

Code Excerpt

// Simple Calculator — Division Function
double divide(double a, double b) {
    if (b == 0) {
        cout << "Error: Division by zero is undefined." << endl;
        return 0;
    }
    return a / b;
}

Library Management System

A console program for borrowing and returning books.

How I built it

  1. Defined the Book data structure holding ID, title, author, and checkout availability status.
  2. Built a Library class managing vector collections of books with add, borrow, and return methods.
  3. Implemented input validation to ensure requested book IDs exist before updating status.
  4. Integrated file storage using fstream to persist library records across application sessions.

Technologies Used

  • C++ (Object-Oriented Programming)
  • Standard Template Library (vector, string)
  • File Streams (fstream) for data persistence

Code Excerpt

// Library Management System — Book Structure
struct Book {
    int id;
    string title;
    string author;
    bool isAvailable;
};

Tools I used

Key tools I use daily, with brief definitions:

VS Code
Visual Studio Code — a free, open-source code editor by Microsoft with built-in Git support, IntelliSense auto-complete, and a rich extension marketplace.
Git
A distributed version-control system that tracks changes to source code, enabling collaboration and safe experimentation through branches and commits.
GitHub
A cloud-hosted platform for Git repositories, providing pull requests, issue tracking, Actions (CI/CD), and portfolio hosting via GitHub Pages.
Chrome DevTools
A set of web-developer tools built directly into Google Chrome, used for inspecting the DOM, debugging JavaScript, profiling performance, and auditing accessibility.
C++ Compiler (g++)
Part of the GCC toolchain; translates C++ source code into executable machine code for systems programming and algorithmic work.
